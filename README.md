# Radio Ip-NeT

🇷🇴 (RO) **Muzica preferată, live, direct pe Android. / 🇬🇧 (EN) Your favorite music live on Android.**

🇷🇴 (RO) Radio Ip-NeT este o aplicație Android pentru ascultarea posturilor Radio Angel și Radio Tequila Club. Alege un post, pornește redarea și continuă să asculți în fundal, inclusiv cu comenzile media din notificare sau de pe ecranul blocat.

🇬🇧 (EN) Radio Ip-NeT is an Android app for listening to Radio Angel and Radio Tequila Club. Choose a station, start playback, and keep listening in the background, including with media controls in the notification or on the lock screen.

## 🇷🇴 (RO) Actualizări automate / 🇬🇧 (EN) Automatic updates

🇷🇴 (RO) Aplicația citește versiunea disponibilă de la `update.ip-net.ro/version.json`. Fișierul de pe server trebuie actualizat după publicarea unei versiuni; valorile necesare pentru Release-ul **1.1.46** sunt în [instrucțiunile updaterului](update-server/README.md). Până la actualizarea serverului, utilizatorii versiunii 1.1.45 pot descărca manual APK-ul nou din Releases.

🇬🇧 (EN) The app reads the available version from `update.ip-net.ro/version.json`. The server file must be updated after a release; the values required for Release **1.1.46** are in the [updater instructions](update-server/README.md). Until the server is updated, users on version 1.1.45 can manually download the new APK from Releases.

🇬🇧 (EN) GitHub Actions builds the Debug version on the `main` branch. A signed Release is published using a tag in the form `vMAJOR.MINOR.PATCH`. The signing key is stored in GitHub Actions secrets; do not upload the keystore file or passwords to the repository.
